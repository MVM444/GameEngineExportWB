# GameEngineExportWB bundled textures

These small demonstration textures are generated procedurally for GameEngineExportWB.
They are original project assets and may be redistributed under the same license as the Workbench.
They are intentionally lightweight and are meant for testing material assignment, UV mapping and Castle visualization rather than for photorealistic production.

Included presets:
- ceramic_light.png
- wood_oak.png
- concrete.png
- stone.png
- brick.png
- ceiling_panel.png
- metal_brushed.png

For production work, users may select their own PNG/JPG/WebP texture files.
